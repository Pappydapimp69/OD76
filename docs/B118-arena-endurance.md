# B118 Arena Endurance

## Problem

The fixed 100-fatigue ceiling forces every battle test to end near the same stage. Arena runs therefore do not create lasting Pip progression, despite highest stage by rank being the strongest playtest achievement.

## Change

- Pip begins with a permanent arena-fatigue maximum of 100.
- Returning from a run banks +4 maximum fatigue for every newly reached all-time-high Pip level. Repeated levels cannot be farmed.
- The new maximum applies on the next battle test; it does not extend the run that earned it.
- The stage-7 merchant returns every five stages and sells three arena snacks per run for 20, 30 and 45 hearts.
- Snacks exist only during that run. Each restores 15 fatigue between stages.
- At zero free fatigue, an owned snack is offered with its remaining count; otherwise the existing return-to-ranch block remains.

## Preserved

Stage fatigue costs, ranch resting, the 60-fatigue arena-entry rule, hunger, hygiene, upgrades, heart banking, ranks and combat difficulty remain unchanged.

## Acceptance

- Old saves migrate to 100 maximum fatigue and best Pip level 1.
- Only new personal-best Pip levels bank endurance.
- Merchant stages, prices, three-item run stock and run reset are exact.
- Exhaustion blocks continuation until a snack is eaten or Pip returns home.
- Fatigue penalties scale against the permanent arena maximum.

## Playtest question

Does the first endurance increase make the second battle test feel meaningfully farther-reaching without making the fatigue wall feel irrelevant?
